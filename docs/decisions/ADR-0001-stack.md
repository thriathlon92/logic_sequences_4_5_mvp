# ADR-0001 — Стек и инженерное окружение

Статус: решения продукта приняты в W00 (2026-10-02); детали W01 готовы к review.

## Решение

React + TypeScript strict + Vite. Runtime backend до коммерческого пилота отсутствует.
Package manager — pnpm через Corepack. Python применяется только для служебных
утилит с uv; Python-проект в W01 не создаётся.

Для воспроизводимости: Node 24.19.0, Corepack 0.35.0, pnpm 10.32.1.
Прямые зависимости закрепляются точными версиями, транзитивные — pnpm-lock.yaml.
Используются ESLint, Prettier, Vitest + Testing Library и Playwright.
Testing Library и jsdom проверяют доступную React-оболочку в Vitest.
CSS пока обычный; выбор визуальной системы отложен.
PWA/service worker подключаются в W24, не в каркасе.

## Основания

Утверждённые решения: разделы 23/W00 и 27 спецификации. Vite предоставляет
статическую сборку и локальный dev server; отдельный сервер продукта не нужен.
[Требования Vite](https://vite.dev/guide/) проверены при создании каркаса.

## Следствия

Не добавляются router, state manager, storage wrapper или schema validator:
для текущего этапа их задача ещё отсутствует. CI использует тот же Node и check,
что локальная проверка. Изменения версий должны обновлять lockfile и проходить check.
