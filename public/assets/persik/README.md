# Persik character assets

Approved visual direction: the simplified five-pose sheet selected before the later facial and coat-pattern corrections.

Files:

- `persik-idle.png` — neutral/idle
- `persik-guide.png` — points toward the primary action
- `persik-thinking.png` — waits/thinks
- `persik-encourage.png` — encourages after an incorrect answer
- `persik-celebrate.png` — celebrates a correct answer

All files use a 512 × 724 px transparent canvas. The artwork was extracted from the approved sheet without redrawing or rescaling.

The source family photographs must not be committed to the application repository.
